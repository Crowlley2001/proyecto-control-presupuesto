# 💰 Control de Presupuesto

Aplicación web para gestionar gastos personales, permitiendo crear un presupuesto, registrar gastos y visualizar el balance disponible en tiempo real.

---

## 🚀 Tecnologías usadas

- React
- TypeScript
- Vite
- Context API
- useReducer
- useState
- CSS

---

## ⚙️ Funcionalidades

- Definir presupuesto inicial
- Agregar gastos con categorías
- Editar gastos
- Eliminar gastos
- Filtrar gastos por categoría
- Visualizar total gastado
- Mostrar saldo disponible
- Persistencia de datos (si usas localStorage puedes agregarlo)

---

## 🧠 Conceptos aplicados

- Manejo global de estado con Context API
- useReducer para lógica compleja
- Custom Hooks (`useBudget`)
- Componentes reutilizables
- Tipado fuerte con TypeScript

---

## 📁 Estructura del proyecto

- components → UI (formularios, listas, etc.)
- context → estado global
- reducers → lógica del estado
- hooks → lógica reutilizable
- data → datos iniciales
- helpers → funciones auxiliares
- types → tipado TypeScript
